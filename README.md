# 🎓 CareerWellness – AI-Powered Career & Wellness Platform

CareerWellness is a modern React-based web application designed to help students prepare for their dream careers while maintaining mental wellness. This platform combines career development tools with wellness support in one interactive solution.

---

## 🚀 Features

- 🧠 AI-Powered Mock Interviews
- 📄 ATS-Friendly Resume Builder
- 🏢 Company Preparation Guides
- 📊 Progress Tracking Dashboard
- 💬 Community Support Section
- 💖 Stress Relief & Motivation Tools
- 🎯 Fully Responsive User Interface

---

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Routing:** React Router DOM
- **Icons:** React Icons / Lucide React
- **Styling:** CSS3
- **Language:** JavaScript (ES6+)
